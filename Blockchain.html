Introduction to Blockchain and Bitcoin

Understanding Bitcoin Blocks, Transactions, Merkle Root & Blockchain Architecture

Blockchain is a decentralized ledger technology that securely records transactions across a network of computers. Introduced in 2008 by Satoshi Nakamoto through the Bitcoin whitepaper, blockchain became the foundation of cryptocurrencies like Bitcoin and Ethereum.

Key Idea: Blockchain removes the need for central authorities by allowing transactions to be verified and stored collectively across a distributed network.

What is Bitcoin?

Bitcoin is a digital currency that operates without banks or governments controlling it. Every transaction made using Bitcoin is stored permanently on the blockchain.

Structure of a Bitcoin Block

A Bitcoin block consists of two major parts:

  • Block Header – Contains metadata and cryptographic information.
  • Block Body – Contains transaction data.
Part Contents Purpose
Block Header Metadata + Merkle Root Identifies and secures the block cryptographically
Block Body Transaction Count + Transactions Stores all transaction records inside the block

1. Block Header (80 Bytes)

The block header is the most critical part of a Bitcoin block. It contains all the information miners use during the mining process.

Field Size (Bytes) Purpose
Version 4 Bitcoin protocol version
Previous Block Hash 32 Links current block to previous block
Merkle Root 32 Hash summary of all transactions
Timestamp 4 Time when block was mined
Difficulty Target 4 Defines mining difficulty
Nonce 4 Value miners change to find valid hash
Total Header Size: 80 Bytes

2. Block Body

The block body contains the actual transaction records. Its size varies depending on the number of transactions included.

2.1 Transaction Counter

This is a variable-length integer that tells the system how many transactions exist inside the block.

2.2 Transaction List

Every transaction contains:

  • Inputs – Source of funds
  • Outputs – Destination address and amount
  • Scripts – Digital signatures and authorization data
  • Locktime – Optional spending delay

Coinbase Transaction

The first transaction in every Bitcoin block is called the Coinbase Transaction.

  • Creates newly mined Bitcoins
  • Rewards miners with BTC + transaction fees
  • Has no actual input transactions

What is a Merkle Root?

A Merkle Root is a single cryptographic hash representing all transactions inside a block.

If even one transaction changes, the Merkle Root changes completely, helping detect tampering instantly.

How Merkle Root is Generated

Step 1: Hash all transactions individually.

Step 2: Pair transaction hashes and hash them again.

Step 3: Continue until one final hash remains.

Final Hash: This becomes the Merkle Root.

Example

Suppose we have 4 transactions:

  • T1 → H1
  • T2 → H2
  • T3 → H3
  • T4 → H4

Pairing process:

  • H1 + H2 → H12
  • H3 + H4 → H34
  • H12 + H34 → Final Merkle Root

How Mining Works

  1. Miner collects pending transactions from the mempool.
  2. Transactions are hashed into a Merkle Tree.
  3. Merkle Root is added to the Block Header.
  4. Miner changes the Nonce repeatedly.
  5. If block hash satisfies difficulty target, block is mined.
  6. Network nodes validate the block.
  7. Block gets added to the blockchain.

How Transactions, Blocks, and Blockchain Work Together

Component Description
Transaction Digital record of Bitcoin transfer
Block Container holding multiple transactions
Merkle Root Single hash summarizing all transactions
Blockchain Connected chain of blocks storing transaction history

Block Size Limits

  • Pre-SegWit: 1 MB maximum block size
  • Post-SegWit: Up to 4 MB weight units

SegWit improved Bitcoin scalability by separating signature data from transaction data, allowing more transactions per block.

Conclusion

Bitcoin and blockchain technology work together through transactions, blocks, cryptographic hashing, and decentralized validation. The Block Header secures the block, the Merkle Root protects transaction integrity, and miners validate everything using Proof-of-Work.

Together, these components create a transparent, tamper-resistant, and decentralized financial system that powers cryptocurrencies worldwide.
